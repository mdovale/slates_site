## Problem, feature, or goal

Writers need a stable page of facts and files about Slates, in the spirit
of The Iconfactory’s press archive: a short index of things you can take,
not a quote wall and not a second marketing home.

URL: `/press` (`press/index.html`). Pretty URLs via a directory, same as
`/support` and `/privacy`.

Entry: one text link at the bottom of the **home page only**, inside the
slot-8 closing band in `index.html`, after the Tot colophon and before
`</main>`. Label: **Press kit**. Href: `press/`.

The shared footer stays Support · Privacy · Email · © on every page,
including home and `/press`. Site nav stays **Features · What’s new ·
Support**. Do not add Press there.

## Context

### What the reference actually is

[files.iconfactory.net/press/](https://files.iconfactory.net/press/) is an
Apache directory index of per-app folders. Tot’s folder
(`/press/Tot/`) holds `App Icons/`, `Branding/`, `Screenshots/`, and a
small `App-Info-Tot.rtf`. Slates has one product, so `/press` is the kit
itself, not a list of apps.

GitHub Pages does not generate directory listings (the repo has
`.nojekyll`). A folder of files with no `index.html` 404s. The analogue
is a hand-written page that lists downloads: name, type, pixel size or
dimensions, and file size. It should look like Slates (dark ground, the
eight numerals, calm copy), not like an Apache index and not like a
generic “in the press” template.

### Page shape

Zero JavaScript. Same chrome as Support: skip link, site bar, eight-dot
strip, `page-title`, measure column, standard footer. Dark page
(`color-scheme: dark`, `theme-color` `#131313`). Links use the page’s
section accent. Slot 8 is a reasonable accent (the home link sits in
band 8); do not invent a ninth color.

Suggested sections, in order:

1. **One paragraph of boilerplate** a writer can copy. Source is
   BLUEPRINT §9 and §10, already public on the home page:
   - Title: Slates
   - Subtitle: *Eight color-coded scratchpads for quick capture.*
   - The one-paragraph description in §9
   - Author: Miguel Dovale
   - Requirements: macOS 14 Sonoma or later
   - Storage line, exact: “Stored locally by default; optional iCloud sync.”
   - No analytics, no third-party sync
   - Contact: `mikedovale@pm.me` (same address as support; used only to reply)
   - Availability: **Coming soon to the Mac App Store.** The live site
     uses `store-soon`, not a store URL. Do not write “Download on the
     Mac App Store” until a listing exists.
2. **A plain-text download** of that same boilerplate, e.g.
   `press/slates-about.txt`. This is the App-Info sheet. UTF-8 `.txt`,
   not RTF. No build step.
3. **App icon.** Link the shipping icon. `images/app-icon.png` is 512×512
   and is what the home closing already uses. Do not upscale it. If a
   1024 px master exists, the owner supplies the file; do not go looking
   in the private app repo’s docs. A 64 px and the apple-touch icon are
   site chrome, not press masters.
4. **Screenshots.** A short curated set of real product windows, linked
   as files. Start from published captures, exported again only if the
   web JPEG is too compressed to hand to a writer:
   - eight slates in a vertical list, dark
   - one slate in focus
   - one light list or focus, if a clean published frame exists
   Prefer window crops from `images/features/win-*` and the v1 list/focus
   stills over lifestyle mockups. Name files boringly
   (`list-dark.png`, `focus-dark.png`). Put press originals under
   `press/`, not in the home page’s `images/` tree, so the home transfer
   stays as it is (§18: home initial transfer ≤ ~900 KB).
5. **Colors.** The eight Slates Dark accents, numerals 1–8 plus the hex
   from `css/tokens.css` (`--slate-1` … `--slate-8`). Number and name
   travel with the swatch. No ninth palette, no Tot colors, no
   “brand gradient.”

Previews on the page, if any, use existing WebP/JPEG exports with real
`alt` text. The download target can be a PNG. Do not inline multi-megabyte
masters as `<img>`.

### Photography and licensing

`resources/` is local source art. Do not `git add` it, do not copy the
tree into `press/`, and do not delete anything under it. Publish only
chosen exports (`BLUEPRINT.md` §8.5, §11.3).

Device-frame mockups in `resources/mockups/` are licensed for this site.
Do not put them in the kit for other people to republish unless the owner
says the license allows that. Product window captures are the kit.

### Pages / URL constraints

- Canonical pattern matches Support:
  `https://mdovale.github.io/slates_site/press/`
  (see `support/index.html` for the head: canonical, description, `og:*`,
  Twitter card, favicon, self-hosted Outfit preload).
- `/`, `/support`, and `/privacy` stay where they are. `/press` is not an
  App Store Support or Privacy URL.
- CNAME exists in the repo. Relative links (`press/` from home,
  `../` from the press page), same as the other pages, so a custom domain
  does not require a second edit.
- Footer markup is duplicated per page, not a template. Changing the
  footer means editing every page. This feature should not do that.
