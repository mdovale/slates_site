## Context

### Structure

- Pretty URLs via directories with `index.html`. All links and assets are **relative** so the same files work at the project path (`/slates_site/`), at a future custom-domain root, and under `python3 -m http.server`.
- Exception: `404.html` has `<base href="/slates_site/">`, because Pages serves it at whatever path was missing. Change to `/` on a custom domain.
- Canonical and Open Graph URLs are absolute on `https://mdovale.github.io/slates_site/`.
- `.nojekyll` so Pages serves files as-is.

### Design system

- `css/tokens.css`: the app’s Slates Dark and Slates Light values per slot (accent, chrome, background, header, digit), copied from the app’s built-in palette JSON.
- `css/site.css`: `.slot-N` sets `--accent`, `--chrome`, `--wash`, `--header`, `--digit`. A `.band` is a slate: a header strip (numbered marker + short label) over a full-bleed wash, copy in a 42rem measure. `.light.slot-N` switches to Slates Light for `/privacy`.
- Links use the section’s chrome color with an accent underline, so they follow the section.
- Numbered markers are rounded squares like the app’s toolbar. The hero strip dims all but the active one and breathes gently; reduced motion turns all motion off.
- Display face: Outfit (SIL OFL), Latin subset, variable 100–900, 30 KB WOFF2, preloaded. Body is the system UI stack.
- `js/home.js` (~35 lines): wraps the hero icon in a button that walks the hero accent through slates 1–8 once. Nothing depends on it.

Commands used (from the repo root):

```bash
magick resources/master-slates-complex/dark_fulldesktop_list_vertical_centered.png \
  -crop 1740x1858+1010+60 +repage -strip /tmp/list.png
magick /tmp/list.png -background '#1c1814' -flatten -quality 82 \
  -sampling-factor 4:2:0 -interlace JPEG images/mac-list-dark.jpg
cwebp -q 80 -m 6 /tmp/list.png -o images/mac-list-dark.webp

magick resources/master-slates-simple/slate_plain_dark.png -strip \
  -background '#1c1415' -flatten -quality 82 images/mac-focus-dark.jpg
magick resources/master-slates-simple/slate_plain_dark.png -strip /tmp/focus.png
cwebp -q 80 -m 6 -exact /tmp/focus.png -o images/mac-focus-dark.webp
```

Icon render (`swift render.swift /path/to/Slates.app icon1024.png 1024`):

```swift
import AppKit
let path = CommandLine.arguments[1]
let out = CommandLine.arguments[2]
let size = CGFloat(Int(CommandLine.arguments[3])!)
let icon = NSWorkspace.shared.icon(forFile: path)
let rep = NSBitmapImageRep(bitmapDataPlanes: nil, pixelsWide: Int(size), pixelsHigh: Int(size), bitsPerSample: 8, samplesPerPixel: 4, hasAlpha: true, isPlanar: false, colorSpaceName: .deviceRGB, bytesPerRow: 0, bitsPerPixel: 0)!
rep.size = NSSize(width: size, height: size)
NSGraphicsContext.saveGraphicsState()
NSGraphicsContext.current = NSGraphicsContext(bitmapImageRep: rep)
icon.draw(in: NSRect(x: 0, y: 0, width: size, height: size), from: .zero, operation: .copy, fraction: 1)
NSGraphicsContext.restoreGraphicsState()
try! rep.representation(using: .png, properties: [:])!.write(to: URL(fileURLWithPath: out))
```
